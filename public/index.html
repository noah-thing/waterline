    [ 02 ]Under the waterline

    Six depths before you click.

    A link looks harmless at the surface. Waterline goes under: it opens the link, plays it, reads everything it loads, then has two AI models confirm what it found.

    1. 000 m

      Address

      Unwraps short links and checks for look-alike names, private networks, known adult hosts and brand-new domains.

    2. 100 m

      Render

      Opens the link in a sealed headless browser. It cannot download files, use a camera or reach a private network.

    3. 200 m

      Play

      Presses Play, taps and mashes the usual keys, then fast-forwards the clock seven minutes to set off anything on a timer.

    4. 300 m

      Code

      Reads every script for ClickFix commands, crypto miners, IP loggers, data-stealing webhooks and adult links.

    5. 400 m

      Images

      Checks every frame and every image the code could load, including pictures hidden inside the code itself.

    6. 500 m

      Judge

      Sends anything flagged to Jev and DeepSeek to confirm or clear, so ordinary games do not get flagged.

    [ Fair use ]
    6 checks per person every 10 minutes, 40 a day.
    [ Kept ]
    Only a 10-minute cache of results, so a link pasted by a whole chat costs one check.
    [ Shown ]
    Captured frames only ever appear pixelated, so nothing explicit reaches the stream.
